# Mini Bank Transaction System

## Author
**P. Nanda Kishore (AP25110090190)**

## Description
A simple C program that simulates a mini bank system. Users can:
- Check balance
- Deposit money
- Withdraw money
- Exit the system

Includes a transaction limit of 5 operations per session.

## How to Compile and Run

### On Windows (using GCC from MinGW or Code::Blocks)
```bash
gcc main.c -o build/mini_bank.exe
build\mini_bank.exe
```

### On Linux / macOS
```bash
gcc main.c -o build/mini_bank
./build/mini_bank
```
