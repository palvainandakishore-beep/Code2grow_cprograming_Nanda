# Cafe Order Management System

## Description
A C program that simulates a simple Café Order Management System.
It allows multiple customers (up to 10) to place orders from a menu of 5 items.

### Features
- Displays a fixed menu with prices.
- Takes multiple customer orders.
- Calculates total bill per customer.
- Shows total revenue, total items sold, most and least ordered items.

## How to Compile and Run
1. Open terminal or command prompt.
2. Navigate to this folder.
3. Compile the program using:
   ```bash
   gcc main.c -o cafe
   ```
4. Run the program using:
   ```bash
   ./cafe
   ```
