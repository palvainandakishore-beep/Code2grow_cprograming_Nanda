# Employee Salary Analyzer

**Author:** P. Nanda Kishore  
**Reg No:** AP25110090190  

This program analyzes employee salaries. It allows the user to:
1. Enter student information (Name, Reg No, Section).
2. Input salaries of multiple employees (up to 10).
3. Perform operations like:
   - Display all salaries
   - Calculate total and average
   - Find highest and lowest salary
   - Count employees above/below average
   - Sort salaries in ascending order

### How to Compile and Run

**To compile:**
```bash
gcc main.c -o salary_analysis
```

**To run:**
```bash
./salary_analysis
```

### Menu Options
1. View Salaries  
2. Find Total and Average Salary  
3. Find Highest and Lowest Salary  
4. Show Employees Above/Below Average  
5. Sort Salaries Ascending  
6. Exit the program
