# Student Marks Analysis System

## Author
**P. Nanda Kishore (AP25110090193)**

## Description
A simple C program that collects marks of multiple students, computes their total, average, and grade, and displays a class summary.

### Features
- Input marks for 3 subjects per student
- Calculates total marks, average, and assigns grade
- Counts passed and failed students
- Displays highest, lowest, and class average marks
- Simple interactive menu system

## How to Run
1. Open terminal in this directory.
2. Compile the program using:
   ```bash
   gcc main.c -o build/student_marks
   ```
3. Run the program using:
   ```bash
   ./build/student_marks
   ```
